# Phone-first setup (GitHub + Android)

This guide is written for someone managing the project from an Android phone without a laptop.

## What you need

- Your Android phone and a GitHub account.
- The VEDA project ZIP.
- A GitHub repository for the source.
- A compatible Qwen `.litertlm` model file downloaded separately.

## 1. Upload the source to GitHub

1. Download and extract the project ZIP using your phone's Files app.
2. Open your GitHub repository in Chrome and choose **Add file → Upload files** (or the equivalent repository upload control).
3. Upload the extracted project folders/files, including `android`, `backend`, `docs`, and `.github`.
4. Do **not** upload the ZIP itself as a substitute for the source tree.
5. Do **not** upload model files, `.env` files, API keys, keystores, or private data.
6. Commit the changes.

If the mobile GitHub interface cannot upload a folder, use GitHub's web upload from a browser in desktop mode or a trusted Git client. Avoid pasting code manually.

## 2. Build a debug APK in GitHub Actions

1. Open your repository's **Actions** tab.
2. Select **Build Android debug APK**.
3. Tap **Run workflow** if the workflow has not started automatically after your commit.
4. Wait for the job to finish. If it fails, open the job logs and note the first Gradle error.
5. Open the successful run and download the `veda-debug-apk` artifact.
6. Extract the artifact ZIP to obtain `app-debug.apk`.

The workflow is a build attempt; success is not a substitute for installing and testing on your phone. The project currently does not include a checked-in Gradle wrapper, so the workflow installs Gradle in the cloud.

## 3. Install the APK

1. Transfer `app-debug.apk` to your phone if it was downloaded elsewhere.
2. Open the APK in Files.
3. If Android asks, allow installing from that specific source (for example, Chrome or Files). This permission is controlled by Android and can be revoked later.
4. Tap Install.

Only install APKs built from a repository you trust.

## 4. Import your Qwen model

1. Open VEDA.
2. Tap **Load Qwen model**.
3. Choose the compatible `.litertlm` model from Downloads.
4. Wait for the model loading status.
5. Try a short prompt first.

The app copies the model to its private app storage. The model is not inside the APK or source ZIP. Keep the original model download because uninstalling VEDA removes its private copy.

## 5. Troubleshooting

- **GitHub workflow fails:** open the first Gradle failure in the logs. Dependency/API compatibility may need fixing before a usable APK can be produced.
- **APK installs but model does not load:** confirm the file is the LiteRT-LM `.litertlm` format supported by the declared runtime, not a Hugging Face `.safetensors` file.
- **Out of memory or very slow generation:** close other apps and try a shorter prompt. The Redmi 13 5G device experience has not been verified here; a 0.6B model can still be slow or memory intensive.
- **No reply:** check that model loading succeeded, then restart VEDA and load it again.
- **Model not visible in picker:** locate it in Downloads or use Android's file picker navigation.

## 6. Updating VEDA

Upload the newer source files to GitHub, commit, run the Android workflow, download the new APK artifact, and install it. Android may offer an update if the package name and signing key match. Debug APKs generated by GitHub Actions can use a different debug key between runs, so Android may require uninstalling the previous debug build first. Uninstalling removes VEDA's private model copy; retain the original model file.
